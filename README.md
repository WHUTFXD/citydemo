# 闵行城运派单系统 Web Demo

本项目高保真复刻现有派单列表与工单详情页，并在不改变原有信息结构的前提下加入悬浮式 AI 推荐与自动派单动画，用于派单能力设计与演示。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:3000`。

## 页面

- `/`：待核验派单列表与约31秒自动派单演示
- `/orders/mh-006`：工单详情与 AI 推荐 Demo
- `/orders/auto-003?focus=address&source=auto-dispatch`：低地址置信度人工干预流程
- `/weekly-report`：智能周报，先分析推荐热点，再确认选题、生成、核验与导出

## 数据

工单演示数据位于 `src/data/work-orders.json`，AI 推荐结果位于 `src/data/ai-recommendations.json`，自动派单时间线与六条动态工单位于 `src/data/auto-dispatch-scenario.json`，全部为虚构脱敏内容。Demo 不调用真实 AI 服务，修改 JSON 后即可调整到达时间、派单结论、置信度、候选地址和目标部门。

## 自动派单演示

在首页打开“自动派单”开关即可播放。工单约每5秒到达，支持暂停、恢复和重播；第三条工单因标准地址置信度不足而置顶等待人工确认，其余工单继续自动流转。

## 高德地图（可选）

复制 `.env.example` 为 `.env.local` 并填写 Web 端 Key 与安全密钥后，可在标准地址推荐中显示真实高德底图。未配置时，其他 AI 推荐和表单回填功能仍可正常演示。

## 智能周报演示

从左侧“智能周报”进入，默认日期为2026年4月20—26日、渠道为12345热线。

1. 点击“分析本期数据”，查看本期与等长比较期统计，以及最多五项推荐热点；默认选中前两项，可调整为最多四项。
2. 确认选题后生成周报。正文和表格中的蓝色统计值可打开数据核验抽屉。
3. 在抽屉查看公式及两期工单，搜索、筛选、分页、打开工单详情；导出完整依据或当前筛选结果为Excel。
4. 各板块可独立重写、补充要求、选择历史版本和标记已核验。导出Word对应当前预览版本。

数据按固定种子生成，覆盖2026年3月1日至5月31日，共约12万条；全渠道每日1220—1380条，其中热线每日365—445条。日期支持1—31天，时间按上海完整自然日计算，比较期为本期前一段等长周期。修改日期或渠道后需要重新分析；修改选题或领导批示开关后需要重新生成。

热点得分由工单量50%、正向增长30%、前三点位集中度20%组成，三项分别按类型最大值归一化。上期不足10件不以增长率加分；上期为零或比较期覆盖不完整时不计算环比。每条工单仅归属一个诉求分类，按唯一编号去重。

本地问答支持“为什么推荐”“加入教育”“移除教育”等选题指令，改写支持“精简表达、突出环比、强调点位、加强建议”及组合。其他开放式要求会提示支持范围，不接入大模型。版本和人工核验状态仅在当前页面会话保留，刷新后重置；模拟数据保持一致。

Excel的“汇总核验、统计口径、本期明细、对比期明细”共用同一统计快照。J列根据工单编号计算计数，K列用分类、点位、业务类型条件公式计算匹配标记，汇总页再以SUM公式复算指标；保留原始精度并随文件保存公式缓存结果。筛选导出明确标注为子集，不冒充完整指标。Excel导出使用独立Worker，避免大批量文件生成阻塞操作。

周报模板参考“现有周报”中的4.13—4.19、4.20—4.26两份文档，提炼了工单概况、热点分析、集中点位、工作建议、上期跟踪、表扬感谢和可选领导批示；演示中的数字与案例来自本地模拟明细，不使用原文数字充当模拟统计。
