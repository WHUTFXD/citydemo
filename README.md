# 闵行城运 Web Demo

Next.js、Tailwind CSS、Ant Design 原型，包含派单与智能简报。分析、语义匹配与研判均为本地有限规则模拟，不调用真实模型服务。已按2026年10月21日业务纪要改版，详见 [调整说明](docs/briefing-redesign-2026-10-21.md)。

## 本地运行

```bash
npm install
npm run dev
```

打开 http://127.0.0.1:3000。独立简报入口为 `/briefing`，首屏选择演示身份，不提供真实鉴权与权限隔离。

## 页面

- `/`：待核验派单列表与约31秒自动派单演示。
- `/orders/mh-006`：工单详情与AI推荐。
- `/orders/auto-003?focus=address&source=auto-dispatch`：低地址置信度人工干预。
- `/briefing`：周报工作台，也保留日报；`/weekly-report`兼容原入口。
- `/ask-data`：独立问数、连续追问、相关工单。
- `/briefing/topic`：专题报，制作方式与统计周期分开设置。
- `/data-trial`：Excel导入、独立试用数据集、质量概览。
- `/templates`：模板增删改查、板块排序、指标绑定。
- `/indicators`：维护指标定义和统计口径，查看异议申报，不展示固化数值。

## 智能简报流程

1. 选择报告类型、可预览模板、统计周期。统一全渠道，比较期为前一连续等长周期。专题报可覆盖近月或自定义起点，“每日制作”仍须手动生成，不代表自动调度。
2. 分阶段分析后出现五个分析板块：市级分类（四级）、区级分类（案件小类）、自定义主题、模型语义识别、词云分析。分类下钻与人工核对沿用原流程。浏览板块不清空选择，选题后可拟定报告标题；自定义与推荐仍互斥。
3. 推荐和自定义主题二选一。支持多关键词、自然语言，如“9月份以来，公建配套中老年人、社区食堂相关诉求”。要素默认同时满足，使用同义表达组；未覆盖主题按原文短语匹配，不宣称任意语义理解。
4. 分类下钻、语义细分保留上级条件。待核对记录在明细第一页顶部黄色高亮并计数，可人工计入或排除；待核对暂不计入统计，人工确认不能突破分类或下钻范围。
5. 生成报告，蓝色统计值打开依据抽屉。独立问数和右下角悬浮助手分析具体场景、诉求构成与两期变化，不把描述性关联冒充现实因果。
6. 复制正文或“导出报告”，沿用参考周报的红色刊头、编制信息、章节与仿宋正文。逐段改写、对照、回退按纪要后置，本期主流程不展示。

样例覆盖2026年9月1日至10月21日，默认10月15—21日；每天约1300条，分类标签仅为演示。按唯一工单编号去重、上海自然日统计。比较期超出数据边界时不计算环比；数据边界不证明范围内每日数据完整。

模型语义识别的正式目标为大模型通读本期全部工单，从共同对象、场景和诉求提炼分类体系之外的热点。当前完全本地演示：后台Worker遍历文本，以共同表达及词语共现模拟最多5个候选，不使用市、区分类字段作为聚类依据。候选可选入报告、下钻、人工核对和导出；未接入真实模型。

词云使用浏览器中文分词（Intl.Segmenter）与城运词典、停用词过滤，统计脱敏摘要和点位的实际词频。字号映射出现次数，列表区分词频与包含原词的去重工单数；点击查看对应工单并导出核验Excel。词云仅为文本线索，不自动等同于热点。空结果、切换周期和导入后均重算；文本计算在Worker中执行。

## 导入与核验

数据试用支持15MB以内、最多15万条的真实.xlsx。9项必需字段：唯一工单编号、受理时间（上海时间）、渠道、业务类型、诉求分类、街镇、标准点位、承办单位、脱敏诉求摘要。可选5项：市级四级分类、区级案件小类、区级案件子类、诉求细分、发生场景。未提供的分类不虚构填充。

支持任意有效日期和原业务分类。全量校验、预览后替换为独立数据集，不与模拟数据混算。核验抽屉内仍提供按编号更新/补入，明确保留文件外工单。拒绝重复编号、空字段、无效日期及原始字段公式；失败不改变当前数据。解析与导出使用Worker。

核验Excel包含统计口径、汇总核验、本期明细、对比期明细，保留数值、日期、复算公式。人工归属和待核对分列，待核对置顶高亮。完整依据不受分页限制，筛选导出明确为子集。核对不修改原始工单；旧报告、问数保留当轮快照，调整后须重新生成。

## 保存范围

模板和指标定义保存在本机localStorage。工单、报告、主题、人工核对、问数、身份与异议均仅当前会话有效，F5恢复样例，不同步给其他同事。

模板槽位须绑定启用且类型、周期兼容的指标，自定义正文可插入 `{{指标编号}}`。生成保存模板与口径快照，修改配置后旧报告待重新生成。指标不支持任意公式。

异议填写原因后可在指标台回复和处理，处理不直接改值。没有真实跨账号通知、后端推送、统一认证或SSO；正式试用仍需业务数据、分类字典、模型与身份服务。

## 原有派单

首页自动派单支持暂停、恢复、重播；第三条地址置信度不足，置顶待确认。虚构数据位于 `src/data/work-orders.json`、`ai-recommendations.json`、`auto-dispatch-scenario.json`。

复制 `.env.example` 为 `.env.local`，配置高德Web Key及安全密钥可显示真实底图；未配置仍可演示地址推荐与回填。

## 检查与部署

```bash
npm run test:weekly
npm run build
npm run start
```

测试覆盖统计、主题、下钻、人工核对、连续问数、模板、Excel及Word，临时文件在忽略的.qa目录。最终Word字体分页仍需客户Word/WPS确认。

GitHub Settings → Pages → Source选择GitHub Actions后，推送main自动发布。`npm run build:pages`本地验证，默认子路径/citydemo，产物out；NEXT_PUBLIC_BASE_PATH可调整。常规构建保留Next.js服务端预览。

生产和Pages均使用Webpack编译后台Worker。工单详情预生成演示编号，查询参数由客户端读取。线上数据属于各访问者浏览器。新版推送main后，由GitHub Actions执行检查并发布。
