# 智能简报原型改版对照

依据：项目根目录《闵行区城运局智能报表工具_功能调整纪要.docx》，会议日期2026年10月21日。

本轮沿用现有Next.js、Ant Design、本地数据和静态部署方式，重排业务流程。没有真实试用工单、分类标准文件、模型服务或身份认证接口，因此原型明确显示样例数据、规则模拟及演示身份，不能作为已完成真实模型试用或正式鉴权的证明。

| 纪要要求 | 原型调整 | 验证方式 |
| --- | --- | --- |
| 周报、问数、专题报优先 | 独立工作台导航按此顺序排列，周报为默认入口 | `/briefing`、`/ask-data`、`/briefing/topic` |
| 用真实工单跑通业务验证 | 数据试用页支持导入Excel，预览并建立独立数据集，不与模拟数据混算 | `/data-trial`；当前会话使用，刷新清空 |
| 合并热点事件和群众热议 | 统一选题流程，不再把二者作为业务分组；所选主题标题可人工拟定 | 周报选题页与生成正文 |
| 待核对置顶、高亮、计数 | 不确定记录排序在明细第一页顶部，黄色高亮；另显示数量及补充筛选 | 主题下钻、数字核验抽屉和Excel |
| 每日专题不等于单日数据 | 专题报区分制作方式和统计周期，支持每天手动制作覆盖近月或自定义起点的报告 | 专题报选择每日制作，再选择9月以来 |
| 多关键词、自然语言、分类子集 | 主题表达支持同义词组与多要素同时匹配，可限定原分类；公建配套中的老人、社区食堂可独立取数 | 自定义主题与问数示例 |
| 市级、区级分类推荐 | 市级四级分类优先，区级案件小类/子类为补充；未提供的分类不自动补造 | 推荐主题两个Tab |
| 分类与语义下钻 | 区级可进入案件子类；分类末级仍可按工单描述细分，保留上级筛选条件 | 主题下钻抽屉及面包屑 |
| 独立开放问数和连续追问 | 对话可以从主题、群体、场景、分类开始，追问沿用当前主题并返回相关工单 | 问数页，蓝色数字及工单入口 |
| 场景与诉求研判 | 比较餐饮、电梯、楼道等场景和具体诉求，保留点位线索；不把文本构成作为已证实因果 | 报告右下角悬浮研判助手 |
| 独立入口及平台入口 | 平台保留入口，新工作台可直接打开，首屏为演示登录 | 平台侧栏及独立地址 |
| 登录鉴权 | 原型仅展示身份选择和登录流程；正式登录、权限及SSO需要后端或统一认证接入 | 登录页明确提示，未伪装真实鉴权 |
| 高级改写后置 | 主流程不展示逐段改写、版本对照及回退，保留复制正文和导出报告 | 报告预览页 |

## 人工核对的统计口径

系统匹配和人工确认计入的工单进入主题数量；待核对工单单列，暂不计入。人工排除不计入。人工确认不能突破当前分类、点位及下钻条件。统计按唯一工单编号去重，不等于按同一事件去重。

人工核对只修改主题的筛选快照，不修改原始工单。已有报告保留旧快照并提示重新生成。核验抽屉展示当前数字对应口径，不能把调整后的统计冒充旧版本结果。历史问数回答也保留当轮快照。

Excel保留市、区分类、场景、人工归属结论和待核对标记。待核对记录置顶高亮，已确认计入列与待核对列分别计算，汇总由公式复算。导出完整记录不受网页分页限制。

## 试用边界

样例覆盖2026年9月1日至10月21日，默认分析10月15日至21日。市、区分类均为演示标签，不代替业务正式分类标准。导入支持原业务分类和任意有效日期，日期边界取自记录，但不证明范围内每日数据均完整；比较期超出边界时不计算环比。

自然语言解析、语义细分和研判是有限规则模拟。未覆盖的主题按原文短语匹配，并提供空结果或明确的范围提示。正式试用须结合业务提供的工单、近期周报、分类字典和模型服务继续校准。

本次改版保留业务派单功能与GitHub Pages静态构建，部署沿用现有GitHub Actions流程。

## 10月22日补充确认：五个分析板块

点击分析本期工单后，提供市级分类（四级）、区级分类（案件小类）、自定义主题、模型语义识别、词云分析五个独立Tab。分类和自定义口径不变；切换Tab仅浏览，选入自定义与推荐时沿用互斥规则。

模型语义识别独立于分类字段：正式方案以大模型读取全量工单，发现共同场景、对象和具体问题；本地Demo以文本表达组合及共现模拟，从本期全部明细归集，使用同一主题规则关联比较期、明细、人工核对和Word/Excel。不把模拟输出描述为已调用大模型。

词云统计本期脱敏摘要及点位，以中文分词、城运词典、停用词过滤生成频次。词频按每次出现计算，去重工单数按包含原词的工单编号计算，界面明确区分。点击词语打开对应工单核验，Excel导出为去重工单依据。全量文本分析使用Worker，不阻塞分类浏览。

验证：41项自动检查通过，生产及Pages构建通过。浏览器已实测分析后五Tab、切换保留选择、语义主题选入报告、词云打开核验、两类文件下载。实际下载Excel包含9077条本期与9131条比较期原始记录，噪声筛选汇总为934件；实际Word包含已采用的“公共空间二手烟暴露”章节及446件匹配工单。样例本期9077条文本聚合在本地Node环境约0.5秒，浏览器使用Worker，耗时随设备和数据变化。

## 工作台滚动分区

桌面端周报与专题报限制在当前视口内，侧栏、顶栏、页面标题和流程保持固定。生成设置的参数独立滚动，标题及分析按钮固定；右侧视图切换、复制与导出、统计概览、五个Tab和底部生成按钮保持可见，仅候选内容与已选主题管理在内部滚动。报告预览仅正文滚动。滚动区域可键盘聚焦，滚动不传递到整页。

该布局仅作用于报告工作台，不改变问数、数据试用、模板、指标和派单页面。宽度900px及以下使用自然纵向布局，避免狭小的多层滚动。浏览器实测：右侧内容滚动505px时整页scrollY仍为0，各固定区域坐标不变；左侧滚动与正文滚动互不影响。800px、390px宽度未出现整页横向溢出。

## 待核对项批量操作

主题核对列表新增复选框，只能勾选待核对记录。支持逐项多选、表头当前页全选、跨分页全选全部待核对；搜索后“全选筛选结果中的待核对”仅覆盖匹配记录。工具栏显示已选数量，提供批量计入、批量排除和清空选择。

翻页保留勾选；切换本期/上期、搜索、只看待核对或下钻范围会清空选择。批量操作保留其他人工结论和无关主题，不修改原始工单；操作后清空勾选、更新数量，已有报告需重新生成。仍仅当前会话保留。新增跨页批量更新回归用例，42项自动检查通过。

生产构建通过。浏览器验证本页全选20条、翻页续选21条、跨页全选639条；搜索后勾选清空。对搜索结果中的1条批量计入后，已计入1434→1435、待核对639→638；再全选并批量排除剩余638条，待核对归零、已计入仍1435，上期1601保持不变。
