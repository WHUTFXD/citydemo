# 闵行城运派单系统 Web Demo

本项目高保真复刻现有派单列表与工单详情页，并在不改变原有信息结构的前提下加入悬浮式 AI 推荐与自动派单动画，用于派单能力设计与演示。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:3000`。

## 页面

- `/`：待核验派单列表与约31秒自动派单演示
- `/orders/mh-006`：工单详情与 AI 推荐 Demo
- `/orders/auto-003?focus=address&source=auto-dispatch`：低地址置信度人工干预流程
- `/weekly-report`：智能报告，选择类型与模板、分析热点、生成及导出
- `/templates`：模板管理，结构配置与指标台绑定
- `/indicators`：指标台，仅维护指标定义与统计口径，支持新增、编辑、复制和启停

## 数据

工单演示数据位于 `src/data/work-orders.json`，AI 推荐结果位于 `src/data/ai-recommendations.json`，自动派单时间线与六条动态工单位于 `src/data/auto-dispatch-scenario.json`，全部为虚构脱敏内容。Demo 不调用真实 AI 服务，修改 JSON 后即可调整到达时间、派单结论、置信度、候选地址和目标部门。

## 自动派单演示

在首页打开“自动派单”开关即可播放。工单约每5秒到达，支持暂停、恢复和重播；第三条工单因标准地址置信度不足而置顶等待人工确认，其余工单继续自动流转。

## 高德地图（可选）

复制 `.env.example` 为 `.env.local` 并填写 Web 端 Key 与安全密钥后，可在标准地址推荐中显示真实高德底图。未配置时，其他 AI 推荐和表单回填功能仍可正常演示。

## 智能报告演示

从左侧“智能报告”进入（路径保留 `/weekly-report`），默认日期2026年4月20—26日。选择日报、周报或专题报，每类提供标准、精简两个可预览模板。已移除统计渠道选择，报告统一按全渠道统计；指标自身可在指标台设置固定渠道口径。

1. 选择报表类型、模板、日期。日报只选一天；周报及专题报支持连续1—31天，比较期为前一等长周期。
2. 点击“分析本期热点”：热点事件与群众热议均按主题归集，不在候选名称中附带地区，也不限定某个点位；群众热议按工单共同诉求归集，不是互联网舆情。每组按工单量50%、正向增长30%、前三点位集中度20%归一化排序，上期不足10件不按增长率加分。
3. 默认各组选中一项，合计最多6项。每个Tab在AI推荐与自定义主题之间二选一，切换后取消本组原选题。推荐模式展示最多5个候选；自定义模式只输入一个具体主题，逐条匹配本期与比较期工单，结果跨原有分类。采用本地同义表达组规则模拟语义识别，仅检索摘要和点位；未收录主题按原文短语匹配，不宣称任意语义理解。抽屉与Excel显示命中原因和可复算规则。主题之间可能交叉，不能相加。
4. 按模板生成报告。蓝色统计值直达工单明细、计算公式和绑定指标的编号、版本、说明。板块保留重新生成、补充要求和历史对照，已移除“确认文字”及确认状态，不再要求逐项确认后下载。
5. 点击“导出报告”导出当前版本Word，沿用两份参考周报的红色刊头、独立期次栏、编制信息下的细红线、黑体章节标题、仿宋正文和首行缩进；网页预览与导出使用同一套版式信息。未提供正式期号、印发日期时不编造，使用演示稿标识及统计截止日期。候选改写未采用时不进入下载文件。

模拟明细覆盖2026年3月1日至5月31日，约12万条；全渠道每天1220—1380条。按上海时间完整自然日和唯一工单编号统计；上期为零或比较期不完整时不计算环比。数据、报告、改写版本和主题在页面路由切换间保留，整页刷新后重置。

### Excel更新与核验

数字明细抽屉支持上传15MB以内的真实`.xlsx`，并提供导入模板。导入表头为：唯一工单编号、受理时间（上海时间）、渠道、业务类型、诉求分类、街镇、标准点位、承办单位、脱敏诉求摘要。也可以修改核验导出的“本期明细”“对比期明细”后上传，额外公式列不作为原始数据导入。

导入前校验全部记录，拒绝缺失字段、重复编号、无效日期或分类、原始字段公式。当前演示仅支持2026年3—5月。通过后按编号更新同号记录，新号补入，不删除文件外工单；自动重新计算分析、热点、报告所有指标与正文，并重置旧改写版本。失败时不修改当前数据。Excel解析与生成使用Worker，导入与导出过程中禁止重复触发。

上传仅在当前会话保留，F5恢复固定模拟数据。原报告保留所选主题的筛选条件，不会因重新推荐而偷偷改成其他点位。统计口径或模板已有变更时，仍提示重新生成，避免继续导出旧口径。

核验Excel包含“汇总核验、统计口径、本期明细、对比期明细”四表，数值、日期和复算公式保留；支持关键词和渠道条件复算。完整依据不受网页分页限制；筛选导出明确标注为子集。

### 模板管理与指标台绑定

`/templates`提供模板新增、预览、搜索、类型筛选、编辑、复制、删除、板块增删及排序。模板和指标定义保存在本机浏览器localStorage，异议与上传数据不持久化。模板全部删除后保留空列表，不自动恢复已删模板。

模板系统板块包含概况、已选主题自动展开、上期跟踪、表扬感谢；各取数槽位必须绑定指标台中已启用的同类型、同周期指标。主题和跟踪使用不限定分类/点位的通用指标，再传入主题条件。自定义正文可通过选择器插入`{{指标编号}}`，生成时以绑定定义计算并建立蓝色指标引用。取数指标被停用或缺失时阻止生成。

指标台默认10项口径（包括新增的通用占比、通用环比），支持新增、编辑、复制、启停。定义维护页不显示具体结果。模板生成保存模板与指标口径快照；修改模板、指标定义或选题后，已有报告标记为待重新生成。指标不支持任意自定义公式。

### 异议申报

数字无异议无需填报；有异议填写原因，提交至指标台“异议申报”工作区。管理员可回复并标记处理中、已处理或不予采纳，完整处理历史同步到数字抽屉。处理不会改变指标值；数据版本更新后旧申报不自动关联新快照。

完全本地演示，没有跨账号通知、真实权限系统或服务端推送。异议及管理员回复仅当前会话有效，F5清空，并清理旧版已存储异议。

### 检查

运行`npm run test:weekly`检查统计、模板绑定、改写、导入、Excel及Word文件，`npm run build`检查生产构建。测试临时文件位于已忽略的`.qa/`。当前环境缺少LibreOffice，Word检查覆盖OOXML内容、红头样式及文件结构；最终字体、分页仍需在客户Word/WPS中确认。


### 报告预览中的AI辅助研判

报告预览仅在右下角提供默认收起的悬浮研判窗口，展开后可选择报告段落作为上下文。选择段落、输入提示词，可围绕增减来源、集中点位、业务类型结构和核查建议进行多轮本地模拟对话。每轮保留原文、报告版本及日期，蓝色数字复用核验抽屉，可继续导出Excel。收起保留对话，开始新对话可清空；报告生成、导入重算或切换正文版本后重新开始，防止混用旧上下文。

研判直接基于段落结构化指标筛选两期工单，不从原文猜测统计口径。多口径或无明确指标的段落会提示改选。支持小基数、上期为零及比较期不完整提示，展示实际点位和业务结构变化；不把变化来源当作已证实的现实成因，不编造天气、政策或现场事实。自由提示词按有限方向规则识别，未支持的请求明确给出可用方向。研判内容不会自动写入报告，所有对话仅在当前页面会话保留。
